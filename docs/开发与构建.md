# 开发与构建

## 项目结构

```text
assets\          图标和设计资源
docs\            用户手册、开发文档
release\         发布版 EXE
src\             主程序源码
tools\           开发与构建脚本
vendor\          vendored 第三方运行库
```

## 主要技术

- Python 3
- Tkinter
- FFmpeg / FFprobe
- tkinterdnd2
- PyInstaller

## 运行源码

```powershell
python src\VideoCutAssistant.pyw
```

也可以双击：

```text
启动视频裁剪助手.bat
```

源码运行时，程序通过根目录的 `vendor` 加载 tkinterdnd2。

## 安装构建依赖

```powershell
python -m pip install -r requirements-dev.txt
```

构建只使用 PyInstaller。
tkinterdnd2 已放置在 `vendor`，不需要单独安装。

## 构建 EXE

```powershell
powershell -ExecutionPolicy Bypass -File tools\build_exe.ps1
```

输出：

```text
release\VideoCutAssistant-v<版本号>.exe
```

默认在构建成功后删除 `build` 中间目录。
如需保留构建日志：

```powershell
powershell -ExecutionPolicy Bypass -File tools\build_exe.ps1 -KeepBuild
```

构建脚本不会内嵌 FFmpeg，EXE 运行时使用系统 FFmpeg。

## 发布前检查

1. 运行 `python -m py_compile src\VideoCutAssistant.pyw`。
2. 使用带空格路径的视频测试拖放。
3. 测试自动检测和手动指定 FFmpeg。
4. 测试删除开头、删除结尾和封面多选处理。
5. 检查输出文件仍包含原始音轨。
6. 检查封面输出中存在 `attached_pic` 图片流。
7. 运行 `tools\build_exe.ps1` 重新生成 EXE。
8. 启动 `release\VideoCutAssistant-v<版本号>.exe` 做冒烟测试。
