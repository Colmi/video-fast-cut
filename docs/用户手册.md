# 视频裁剪与封面助手 - 用户手册

## 1. 功能概述

本程序用于：

- 删除视频开头的指定秒数。
- 删除视频结尾的指定秒数。
- 从指定秒抽取画面并设置为视频内嵌封面。
- 同时执行上述任意多个任务，只生成一个输出文件。
- 在程序内快速预览视频、时间轴和不同清晰度画面。
- 查看当前操作对应的 FFmpeg 指令。
- 自动检测或手动指定系统 FFmpeg。

原视频不会被修改。

## 2. 运行环境

- Windows 10 或 Windows 11，64 位。
- 打包版不需要安装 Python。
- 必须能够使用系统 FFmpeg。
- 如果 FFmpeg 不在系统 PATH 中，可在程序内手动指定 `ffmpeg.exe`。

官方下载页：

<https://ffmpeg.org/download.html>

## 3. 启动程序

打包版：

```text
release\VideoCutAssistant-v1.2.0.exe
```

源码版：

```text
启动视频裁剪助手.bat
```

源码版需要安装 Python 3.10 及以上版本。

## 4. 选择视频

支持两种方式：

1. 点击“选择视频…”。
2. 将视频文件直接拖到上方视频地址栏。

支持的主要格式：

```text
MP4、MKV、MOV、M4V、AVI、WMV、FLV、WEBM、
TS、M2TS、MTS、MPG、MPEG、VOB、OGV、3GP
```

一次拖入多个视频时，程序载入第一个有效视频。

## 5. 界面说明

右侧面板从上到下依次为：

1. FFmpeg 环境
2. 操作方案
3. 路径
4. FFmpeg 指令

### FFmpeg 环境

该区域可以展开或折叠。

- 首次运行时默认展开。
- 完成初次设置后，后续启动默认折叠。
- 未检测到 FFmpeg 时自动展开。
- 显示当前 FFmpeg 版本和 `ffmpeg.exe` 路径。
- 支持“自动检测”“手动选择…”和“应用路径”。
- 未检测到 FFmpeg 时显示“官方下载页”。

如果手动选择 FFmpeg 所在目录中的 `ffmpeg.exe`，程序会优先寻找同目录的 `ffprobe.exe`，并记住该路径。

### 操作方案

三个任务可以任意多选：

- 删除开头
- 删除结尾
- 修改封面

每个任务有独立的秒数输入框。

“取预览”按钮的取值规则：

- 删除开头：填入当前预览位置的秒数。
- 删除结尾：填入“视频总时长 − 当前预览位置”。例如全片 10 秒，预览停在 3.25 秒，则删除结尾填写 6.75 秒。
- 修改封面：填入当前预览位置的秒数。

### 路径

输出目录默认使用源视频所在目录。

如需保存到其他位置：

1. 取消勾选“默认使用源视频目录”。
2. 点击“手动指定…”，选择目标目录。
3. 也可以直接在目录输入框中编辑路径。

程序会根据输入视频文件名自动生成输出文件名：

```text
仅裁剪：原文件名-cut.原扩展名
仅封面：原文件名-cover.原扩展名
裁剪并修改封面：原文件名-cut-cover.原扩展名
```

如果手动指定的目录不存在，程序会在开始处理前询问是否创建。

### FFmpeg 指令

该区域默认折叠。

展开后可以看到当前已经勾选操作对应的 FFmpeg 指令。
勾选状态、秒数、精确模式、视频文件或输出名称变化时，指令会实时更新。

封面临时图片在指令中显示为：

```text
<cover.jpg>
```

## 6. 输出格式与 MKV 转 MP4

“操作方案”中提供“输出格式”选项：

- 保持源格式：输出扩展名和源文件一致。
- 转换为 MP4：将输出封装为 MP4。

当源文件为 MKV，且主视频流为 AVC/H.264 时，程序会自动推荐“转换为 MP4”。

转换规则：

- 主视频流直接复制，不重新编码。
- AAC、MP3、AC3、EAC3、ALAC 音频直接复制。
- Opus、Vorbis、DTS 等不兼容音频自动转换为 AAC 192 kbps。
- SRT、ASS、SSA、WebVTT 等文本字幕转换为 MP4 mov_text 字幕。
- PGS、VOBSUB 等图形字幕不写入 MP4。
- 附件不写入 MP4。
- 编码为空的未知流、数据流和不兼容流会被安全跳过。
- 如果没有 ffprobe 流信息，MP4 输出会只保留主视频和音频，音频统一转 AAC。
- 封面对 MP4 转换继续有效。
- 输出文件自动添加 `-movflags +faststart`，方便播放和网络分发。

如果需要保留所有 MKV 字幕和附件，请选择“保持源格式”。
## 7. 快速预览

预览区支持：

- 拖动时间轴。
- 后退 1 秒。
- 后退 5 秒。
- 播放预览。
- 前进 5 秒。
- 前进 1 秒。

时间轴范围：

- 完整视频：进度条对应整部视频。
- 仅前10分钟：进度条仅对应视频开头 10 分钟，便于精细选择封面。

切换按钮位于“预览清晰度”下拉框右侧。

清晰度下拉选项：

```text
480×270（最快）
560×315（快速）
720×405（清晰）
960×540（高清预览）
```

预览按照源视频画幅等比缩放，不会强制补成 16:9 黑边。
预览区会显示：

- 实际预览输出尺寸。
- 源视频画面尺寸。

预览为静音低分辨率帧流，不生成持久预览文件。

## 8. 删除开头或结尾

1. 勾选“删除开头”或“删除结尾”。
2. 输入需要删除的秒数。
3. 选择快速无损或精确裁剪。
4. 点击“一键处理”。

### 快速无损

默认模式，直接复制视频和音频编码流。

优点：

- 速度快。
- 编码和主要封装设置保持不变。

限制：

- 切点可能落在目标时间附近的最近关键帧。
- 不保证精确到指定秒数。

### 精确裁剪

会重新编码主视频，切点可准确到帧。

注意：

- 处理速度较慢，尤其是 4K/H.265 视频。
- 视频编码参数和文件大小可能变化。
- 音频仍尽量直接复制。

## 9. 设置封面

1. 勾选“修改封面”。
2. 输入封面画面所在的原始视频时间。
3. 可以先用预览定位画面，再点击“取预览”。
4. 点击“一键处理”。

封面会作为 JPG 图片流嵌入输出视频。
内嵌封面目前支持 MP4、M4V、MOV 容器。

封面时间按原视频时间计算，不会因为同时删除开头而改变。

## 10. 统一处理多项任务

可以同时勾选：

- 删除开头
- 删除结尾
- 修改封面

程序只执行一次处理，并生成一个组合结果文件。

示例：

```text
删除开头 10 秒
删除结尾 20 秒
使用原视频第 300 秒作为封面

输出：原文件名-cut-cover.原扩展名
```

## 11. 输出与安全

- 原视频不会被覆盖。
- 输出保存在原视频目录。
- 如果输出文件已存在，程序会询问是否覆盖。
- 处理过程中可以点击“取消”。
- 取消或失败时，临时处理文件会自动清理。

## 12. 常见问题

### 程序提示未检测到 FFmpeg

处理方法：

1. 展开“FFmpeg 环境”。
2. 点击“手动选择…”。
3. 选择系统中的 `ffmpeg.exe`。
4. 点击“应用路径”。
5. 或点击“官方下载页”获取 FFmpeg。

### 裁剪时间不准确

关闭精确裁剪时使用流复制，切点会受关键帧影响。
需要逐帧准确时，请勾选“精确裁剪”。

### 已选择 FFmpeg，但提示找不到 ffprobe

如果同目录没有 `ffprobe.exe`，程序会使用 FFmpeg 读取基础信息。
建议选择完整的 FFmpeg 发行包，确保 `ffmpeg.exe` 和 `ffprobe.exe` 位于同一目录。

### Windows 提示未知发布者

程序未使用商业代码签名证书。
确认文件来自本项目后，可选择“更多信息”→“仍要运行”。

### 拖放没有反应

- 确认拖放的是文件，而不是文件夹。
- 确认扩展名在支持列表中。
- 可以改用“选择视频…”按钮。

## 13. 设置文件

程序会记住手动指定的 FFmpeg 路径和折叠状态，配置文件位置：

```text
%APPDATA%\VideoCutAssistant\settings.json
```

删除该文件可以恢复首次运行状态。
